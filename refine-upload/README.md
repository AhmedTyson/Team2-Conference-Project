# Refine Upload — Single-File Frontend Pack

Self-contained HTML pages of the Itinari frontend (conference project). Each page has ALL its CSS and JS **inlined** — one file = one page. Upload any file to your refine tool / AI chat.

## Pages

| File | Route |
|---|---|
| `index.html` | Landing («Itinera – AI Travel Planner», from deepseek export) |
| `login.html` / `forgot.html` / `reset.html` / `verify.html` / `register.html` | Auth flow |
| `dashboard.html` | User dashboard |
| `admin/index.html`, `admin/users.html`, `admin/user-details.html`, `admin/trips.html`, `admin/destinations.html`, `admin/hotels.html`, `admin/restaurants.html`, `admin/countries.html`, `admin/attractions.html`, `admin/reviews.html`, `admin/analytics.html`, `admin/settings.html` | Admin panel (12 pages) |

## Notes

- Google Fonts + GSAP stay on CDN (kept external intentionally); everything else inline.
- API base `http://127.0.0.1:8001/api` (see `config.js` inside each file) — swap to any backend URL.
- Auth token stored as `itinari_token`; admin pages redirect to `/login.html` when unauthenticated (works on a static host; under `file://` the redirect resolves to drive root — serve over http when previewing).
- Generated by `build`/`refine-inline.mjs` (one-time inline pass), Oct 2026. Regenerate from `frontend/` if the app changes.
- `index.html` landing comes from the deepseek web export; the repo itself has no root landing page.

## Structure kept

- Relative paths preserved (`admin/*`, `assets/…`) so the folder also runs as-is on any static host.
